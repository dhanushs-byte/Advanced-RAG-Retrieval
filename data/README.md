# Input documents

By default, this project reads your existing Week7-Day1 documents from:

`../Week7-Day1/data`

Supported formats: PDF, DOCX, TXT and MD.

If your Week7-Day1 folder is elsewhere, change `DATA_DIR` in `.env`.
Do not put `.env` or API keys in GitHub.

The evaluation question files in this folder are editable. Update their
`expected_terms` to phrases that actually appear in your own documents.
